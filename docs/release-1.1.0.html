01四种模式，外加一种失控

开关点一下收起，再点一下展开，不自动。想完全自己掌控节奏的时候用它。
不看还看点开看十秒，时间到自动合上；想再看，再点一下。默认模式。
无聊盒子猫从箱子里探出头，十秒后屏幕外伸下来一只手把盒子按回去。
抓狂模式棋子在图标缝里跳，前三次抓不到；第四次抓住后消失，再从上方落回原位。
混沌模式延时、到时动作、两张状态图、两个音效、切换效果，全部自己定；内置整套素材，也能上传自己的图片和声音。

  • 状态栏图标统一成一套，深色菜单栏自动换成白色版本。

03安装

下载对应芯片的 dmg，打开后把 BlankTop 拖进「应用程序」。第一次折叠时按提示到「系统设置 → 隐私与安全性 → 辅助功能」里授权即可，不需要重启。

04安装失败 / 打不开怎么办

提示「BlankTop 已损坏，无法打开」

这是 macOS 对未公证应用的隔离标记。打开「终端」执行下面这行，然后再打开：

xattr -dr com.apple.quarantine /Applications/BlankTop.app
提示「无法验证开发者」或「来自身份不明的开发者」

在 Finder 里按住 Control 点 App →「打开」→ 再点「打开」；或者到「系统设置 → 隐私与安全性」底部点「仍要打开」。

辅助功能里勾了，但点击还是没反应

换过签名或重新编译后，系统里的旧授权会“勾着但不生效”。到「隐私与安全性 → 辅助功能」，选中旧的 BlankTop 按 − 删除，再点 + 重新添加 /Applications/BlankTop.app，然后重新打开 App。

折叠后连 BlankTop 自己的图标也被藏起来了

说明 App 不在 /Applications 下。系统的菜单栏白名单只对这个目录里的 App 生效，把 App 拖进去再启动即可。

点击菜单栏图标没反应，或者一次开了两个

BlankTop 有单实例保护：重复启动会直接退出。先到活动监视器里结束所有 BlankTop，再从「应用程序」打开一份。

下载错了芯片版本 / 打开就闪退

苹果菜单 →「关于本机」→「芯片」：显示 Apple M 系列就用 arm64 版，显示 Intel 就用 intel 版。装错版本通常会在启动时直接退出。

自动收起没有生效

先确认当前模式是「不看还看」或「无聊盒子」，并且「设置 → 辅助功能」已授权。1.1.0 已修复“启动时不计时”的问题；如果仍不生效，打开日志看看有没有 auto close。

想彻底卸载

退出 App，删除 /Applications/BlankTop.app；再删掉配置和开机项：

rm -rf ~/Library/Application\ Support/BlankTop
rm -f ~/Library/LaunchAgents/com.xa.blanktop.plist
日志在哪

菜单里点「打开日志」，或者直接看 ~/Library/Logs/BlankTop.log。反馈问题时把最后几十行一起发出来最有用。
